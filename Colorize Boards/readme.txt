[center][size=5][b]Colorize Boards - v1.0.2[/b][/size]
[b]Custom Board & Category Colours for SMF 2.1.x[/b]
[b]By BoredSkull[/b][/center]
[hr]
[b]Overview[/b]
Bring a splash of colour to your SMF forum with Colorize Boards, allowing administrators to customise board and category names and descriptions with individual colours and optional bold or italic formatting.
Inspired by the original Colorize Boards modification, this version has been rebuilt using updated coding practices for SMF 2.1.x, providing a modern, lightweight implementation while retaining the original concept.
[color=green][b]Uses SMF hooks. No core or theme file edits required![/b][/color]
[hr]
[b]Features[/b]
[list]
[li][b]Board Colours[/b] - Customise individual board names and descriptions.[/li]
[li][b]Category Colours[/b] - Assign separate colours to category names and descriptions.[/li]
[li][b]Text Formatting[/b] - Apply optional bold or italic styling to names.[/li]
[li][b]Colour Picker[/b] - Select colours visually or enter hexadecimal codes or colour names.[/li]
[li][b]Global Toggle[/b] - Enable or disable the modification through the administration panel.[/li]
[li][b]Theme Friendly[/b] - Leave colour fields blank to retain the theme's default styling.[/li]
[/list]
[hr]
[b]Installation & Configuration[/b]
Install the package through [b]Admin > Packages > Download Packages > Upload Package[/b], then select [b]Install Now[/b].
To configure colours:
[list]
[li]Navigate to [b]Admin > Forum > Boards > Modify Boards[/b].[/li]
[li]Edit a board or category to access the additional styling options.[/li]
[li]Choose a colour using the picker, hexadecimal value (e.g. #ff0000) or colour name (e.g. red).[/li]
[li]Leave fields blank to preserve the default theme colours.[/li]
[/list]
The modification can be enabled or disabled under [b]Admin > Forum > Boards > Settings[/b].
[hr]
[b]Where Colours Appear[/b]
Custom colours are applied throughout the forum, including:
[list]
[li]Board index and child boards[/li]
[li]Category headings[/li]
[li]Message index headers[/li]
[li]Linktree navigation[/li]
[li]Board links in Recent Posts, Statistics, Unread Posts and search results[/li]
[/list]
[hr]
[b]Technical Notes[/b]
[list]
[li][b]100% Hook Based[/b] - No modifications to SMF core files or theme templates.[/li]
[li][b]Updated Implementation[/b] - Rebuilt for SMF 2.1.x using modern coding practices rather than relying on the original modification's implementation.[/li]
[li][b]No Database Changes[/b] - Colour preferences are stored in a single setting without creating or modifying database tables.[/li]
[li][b]Theme Compatibility[/b] - Supports the default SMF theme and custom themes retaining standard board and category markup (#board_X and #category_X).[/li]
[/list]
