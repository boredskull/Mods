[b]Social Media Links[/b] allows forum members to share their favourite social media profiles, displaying them as a clean, organised row of icons directly [b]below their signature[/b] on every forum post.

No cluttered signatures, no complicated setup and no unnecessary modifications to SMF's core files.

Simply install, configure and let your members connect!

[size=3][color=#2980b9][b]How Does It Work?[/b][/color][/size]

Once a member adds their social media profiles, the corresponding icons automatically appear below their signature.

[code]
Forum Post
────────────────────────
Member's Signature
────────────────────────
Social Media Icons
[/code]

Each icon links directly to the member's profile, allowing other community members to discover and follow them.

[b]No manual BBCode or signature editing is required![/b]

[size=3][color=#2980b9][b]Easy Profile Management[/b][/color][/size]

Members can add, update or remove their social media links directly from their forum profile.

[center][b][color=#27ae60]Profile > Modify Profile > Social Media Links[/color][/b][/center]

The modification makes adding links straightforward by supporting multiple input formats.

[b]Members can enter:[/b]
[list]
[li]A username, such as [i]name.bsky.social[/i][/li]
[li]A complete social media profile URL[/li]
[li]A Mastodon address using [i]@user@instance[/i][/li]
[/list]

Supported inputs are automatically processed into the appropriate profile links.

[color=#27ae60][b]Simple for members. Easy to manage for administrators.[/b][/color]

[b]Features include:[/b]
[list]

[li]Support for usernames and complete profile links[/li]
[li]Compatibility with federated Mastodon and Pixelfed instances[/li]
[li]Checks against unrelated domains masquerading as social network links[/li]
[li]Permission-based control over link management and visibility[/li]
[/list]

[size=3][color=#2980b9][b]Font Awesome Icons[/b][/color][/size]

The modification uses [b]Font Awesome Free[/b] to display recognisable social media icons without requiring individual image files.

By default, Font Awesome is loaded through the [b]cdnjs CDN[/b].

Administrators have three options:

[list]
[li][b]Default CDN:[/b] Use the supplied cdnjs-hosted stylesheet.[/li]
[li][b]Self-Hosted:[/b] Specify the URL of a locally hosted Font Awesome stylesheet.[/li]
[li][b]Existing Theme Support:[/b] Leave the stylesheet setting blank if the forum theme already includes a suitable version of Font Awesome.[/li]
[/list]

[color=#d35400][b]Important:[/b][/color] Font Awesome [b]6.5 or newer[/b] is required for the Bluesky icon.

[size=3][color=#2980b9][b]Advanced Permission Controls[/b][/color][/size]

Social Media Links integrates directly with SMF's existing permission system.

Administrators can decide who is allowed to add social media links, manage other members' links and view social media icons.

[b]Permission Settings:[/b]

[center][color=#27ae60][b]Admin > Permissions > General Permissions > Profile[/b][/color][/center]

[b]Available permissions:[/b]
[list]
[li][b]Add social media links below signature[/b] - Own profile / Any profile[/li]
[li][b]See social media icons on posts[/b][/li]
[/list]

[b][color=#27ae60]Default Permissions After Installation[/color][/b]
[list]
[li][b]Regular Members:[/b] Can add and edit their own social media links.[/li]
[li][b]Global Moderators:[/b] Can manage social media links on any member's profile.[/li]
[li][b]Everyone, including Guests:[/b] Can view social media icons on posts.[/li]
[/list]

[b][color=#27ae60]Post Count Based Permissions[/color][/b]

Want to make social media links a benefit for established members?

You can configure permissions based on post count groups, allowing only members who meet a certain posting threshold to display their links.

For example, you could allow members with [b]50 or more posts[/b] to add social media links.

To enable this functionality, navigate to:

[b]Admin > Permissions > Settings[/b]

Enable:

[i]Enable permissions for post count based groups[/i]

Then configure the desired permissions for your post count groups.

[color=#d35400][b]Important:[/b][/color] If a member loses permission to display their social media links, their icons are hidden automatically.

Their saved links are [b]not deleted[/b], meaning they can be displayed again if the member regains permission.

[size=3][color=#2980b9][b]Custom Theme Compatibility[/b][/color][/size]

Most themes retaining SMF's standard signature output functionality should work without modification.

However, some heavily customised themes may have removed the built-in below-signature area.

If your theme does not include this area, the social media icons may not appear.

[b][color=#d35400]Custom Themes Only:[/color][/b]

If the below-signature output area is missing, add the following code to your custom theme's [b]Display.template.php[/b], immediately after the signature output:

[code]
if (!empty($message['custom_fields']['below_signature']))
{
    echo '<div class="custom_fields_below_signature"><ul class="nolist">';
    foreach ($message['custom_fields']['below_signature'] as $custom)
        echo '<li class="custom ', $custom['col_name'], '">', $custom['value'], '</li>';
    echo '</ul></div>';
}
[/code]

[color=#27ae60][b]Note:[/b][/color] This additional step is only necessary if your custom theme has removed the relevant SMF output area.

Standard SMF themes do not require this modification.

[size=3][color=#2980b9][b]Uninstallation[/b][/color][/size]

Social Media Links can be uninstalled through SMF's Package Manager.

During uninstallation, you will have the option to select:

[b]"Remove all data associated with this modification"[/b]

If selected, this removes:
[list]
[li]Stored member social media links[/li]
[li]Modification-specific permissions[/li]
[li]Modification settings[/li]
[/list]

[color=#d35400][b]Important:[/b][/color] Selecting this option permanently deletes the stored social media information.

If you plan to reinstall the modification and wish to retain your members' links, leave this option unchecked.
